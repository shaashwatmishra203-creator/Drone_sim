Factory hall mission: replay of a recorded simulation run

The drone takes off from the pad, flies a factory aisle using only what its camera sees, scans the room at the far end, and flies back to land. Camera frames go over an emulated WiFi link to a cloud object detector; the boxes that come back become the drone's map (red). The path shown is the drone's true position recorded from Gazebo.
Simulation only (PX4 SITL + Gazebo Harmonic + ROS 2). This is a recording of one run, replayed in your browser. It does not show that the real aircraft is safe to fly.
